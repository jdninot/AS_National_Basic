# Basic Analysis of the National and Regional Situation

This repository contains R scripts for processing and consolidating Colombia’s official vital statistics and population projection data, including deaths, maternal deaths, births, and population projections. The scripts process annual raw microdata files to support demographic and public health analyses at the national and departmental levels.

## Data Sources

All data are obtained from official releases published by Colombia’s National Administrative Department of Statistics (DANE):

- **Vital Statistics:** Annual data on deaths, maternal deaths, and births.  
  https://www.dane.gov.co/index.php/estadisticas-por-tema/demografia-y-poblacion/nacimientos-y-defunciones

- **Population Projections (2018–2023):** Official population projection data.  
  https://www.dane.gov.co/index.php/estadisticas-por-tema/demografia-y-poblacion/proyecciones-de-poblacion
